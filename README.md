# 📄 Worksheet Generator

A desktop application built with **Python** and **PyQt6** that allows teachers to quickly create customizable classroom worksheets and export them as professionally formatted Word documents.

---

## ✨ Features

* 📝 **Custom Worksheet Title**
* 🔤 **Multiple Activity Types**

  * Fill in the Blanks
  * Unscramble Words
  * Word Search Generator
* 🔍 **Dynamic Word Search**

  * Adjustable grid sizes (8×8 up to 20×20)
  * Difficulty levels (Beginner, Medium, Hard)
  * Automatic word placement with multiple directions
* 🎨 **Text Formatting Tools**

  * Bold, Italic, Underline
  * Adjustable font sizes
* 📋 **Student Info Header**

  * Optional Name, Date, and Class fields
* 📄 **Export to Word (.docx)**

  * Clean worksheet layout
  * Automatically generated answer sheets

---

## 🛠 Tech Stack

* Python
* PyQt6 (GUI)
* python-docx (document export)

---

## 🎯 Purpose

This tool is designed to help teachers save time by generating engaging, printable worksheets with minimal effort. It’s especially useful for language learning environments and young learners.

---

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```

2. Navigate into the project folder:

   ```bash
   cd your-repo-name
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python main.py
   ```

---

## 📌 Notes

* Make sure you have Python 3.10+ installed
* The application exports `.docx` files, so Microsoft Word or a compatible program is recommended
